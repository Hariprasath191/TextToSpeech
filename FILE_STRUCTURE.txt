🔄 APPLICATION FLOW
───────────────────

1. User opens browser → http://localhost:5000
   ↓
2. Server sends index.html + style.css + script.js
   ↓
3. User enters text and selects tone
   ↓
4. script.js sends request to app.py
   ↓
5. app.py generates speech using pyttsx3
   ↓
6. Audio processed with pydub
   ↓
7. MP3 file saved to static/audio/
   ↓
8. URL sent back to browser
   ↓
9. Audio plays in browser
   ↓
10. User can download the file
