PROJECT OVERVIEW
----------------
This is a complete, working web application that converts text to speech with
multiple emotional tones using AI-powered speech synthesis technology.

The system features a modern, professional user interface with 7 different 
voice tones, male/female voice options, and the ability to download generated 
audio files.


WHAT'S INCLUDED
---------------
✓ Complete Flask web application (app.py)
✓ Modern responsive HTML interface (templates/index.html)
✓ Professional CSS styling (static/css/style.css)
✓ Interactive JavaScript (static/js/script.js)
✓ Python dependencies list (requirements.txt)
✓ Comprehensive documentation (README.md)
✓ Setup guide (SETUP_GUIDE.txt)
✓ Installation test script (test_installation.py)
✓ Easy run scripts (run.sh for Mac/Linux, run.bat for Windows)


KEY FEATURES
------------
1. Text-to-Speech Conversion
   - Convert any text up to 5000 characters
   - Natural-sounding speech synthesis
   
2. Multiple Voice Tones (7 Options)
   - Neutral: Balanced and clear

   - Sad: Somber and low
   - Calm: Peaceful and soothing
   - Energetic: Fast and dynamic
   - Professional: Formal and clear

3. Voice Gender Selection
   - Male voice option
   - Female voice option

4. Audio Features
   - Real-time audio generation
   - In-browser audio playback
   - Download as MP3 files
   - High-quality 192kbps bitrate

5. User Interface
   - Modern, gradient-based design
   - Fully responsive (mobile-friendly)
   - Smooth animations
   - Real-time character counter
   - Error handling and user feedback

QUICK START GUIDE
-----------------

OPTION 1: Automatic Setup (Recommended)

  Windows:
    1. Double-click 'run.bat'
    2. Wait for setup to complete
    3. Browser opens automatically to http://localhost:5000

  Mac/Linux:
    1. Open Terminal in project folder
    2. Run: ./run.sh
    3. Open browser to http://localhost:5000


OPTION 2: Manual Setup

  1. Install FFmpeg (REQUIRED for audio processing)
     - Windows: Download from https://ffmpeg.org
     - Mac: brew install ffmpeg
     - Linux: sudo apt install ffmpeg

  2. Install Python dependencies:
     pip install -r requirements.txt

  3. Run the application:
     python app.py

  4. Open browser to:
     http://localhost:5000

TECHNICAL DETAILS
-----------------

Text-to-Speech Engine:
  - Uses pyttsx3 library
  - Supports system-installed voices
  - Offline processing (no internet required)

Audio Processing:
  - Pitch adjustment via sample rate manipulation
  - Speed control using pydub
  - MP3 export with 192kbps bitrate

Tone Implementation:
  - Rate: Controls words per minute (120-200 WPM)
  - Pitch: Multiplier for frequency (0.8-1.3x)
  - Speed: Playback speed adjustment (0.9-1.2x)

File Management:
  - Automatic cleanup of files older than 1 hour
  - Unique timestamped filenames
  - Temporary WAV → Final MP3 conversion


API ENDPOINTS
-------------
POST /generate
  - Generates speech from text
  - Parameters: text, tone, voice_gender
  - Returns: audio URL and filename

GET /download/<filename>
  - Downloads generated audio file
  - Returns: MP3 file

POST /cleanup
  - Removes old audio files
  - Called automatically on page load


CUSTOMIZATION OPTIONS
---------------------

1. Modify Voice Tones
   Edit TONE_SETTINGS in app.py:
   
   TONE_SETTINGS = {
       'custom': {
           'rate': 150,     # 50-300 words/minute
           'pitch': 1.0,    # 0.5-2.0 multiplier
           'speed': 1.0     # 0.5-2.0 multiplier
       }
   }

2. Add New Tones
   - Update TONE_SETTINGS in app.py
   - Add tone card in index.html
   - Update styling in style.css

3. Change Port
   Edit app.py, last line:
   app.run(debug=True, host='0.0.0.0', port=5000)

4. Adjust UI Colors
   Edit CSS variables in style.css:
   --primary-color: #6366f1;
   --secondary-color: #8b5cf6;


TROUBLESHOOTING
---------------

Problem: "Module not found" error
Solution: pip install -r requirements.txt

Problem: FFmpeg not found
Solution: Install FFmpeg and add to system PATH

Problem: No voices available
Solution:
  - Windows: Install Microsoft Speech Platform
  - Linux: sudo apt-get install espeak

Problem: Port 5000 already in use
Solution: Change port in app.py (see Customization)

Problem: Audio won't play
Solution:
  - Try different browser (Chrome recommended)
  - Check browser console (F12)
  - Verify FFmpeg installation
